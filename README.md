# Тестовое задание — аналитик ценообразования

## Задание 1. Конкурентный анализ

**Что сделал:** проверил данные, исключил неактивные правила, назначил наценки по иерархии и рассчитал регулярные цены, индексы конкурентов и рекомендуемые скидки с целевой маржинальностью 10%.

**Результат:** по расчёту для **527 из 683 SKU** можно установить минимальную рыночную цену, для **156 SKU** предложена стоп-цена; средняя скидка — **22,32%**, медианная — **20,14%**.
Средний индекс цен относительно Ozon — **1,318**, Wildberries — **1,296**, tsum.ru — **1,006**.
Даты начала действия правил не проверены, а округление стоп-цены может дать фактическую маржинальность чуть ниже 10%.

## Задание 2. Скидка для удвоения продаж

**Что сделал:** рассчитал средние дневные продажи по уровням относительной цены и построил логарифмические регрессии для оценки эластичности спроса каждого из 10 SKU.

**Результат:** модельная скидка для удвоения продаж относительно уровня без скидки — **19,9–24,8%**, в среднем **22,91%**; эластичность — от **−3,13 до −2,43**.
Оценка не гарантирует будущего удвоения продаж: сезонность, другие факторы спроса и изменение регулярной цены отдельно не учитывались.

## Задание 3. Недельная динамика продаж

**Что сделал:** сравнил выручку, валовую прибыль и взвешенную маржинальность недель 14 и 15, оценил вклады брендов и разложил изменение маржинальности на структурный эффект и изменение маржи брендов.

**Результат:** выручка снизилась на **256,28 млн руб.**, валовая прибыль выросла на **30,20 млн руб.**, маржинальность увеличилась с **14,63% до 15,45%** — примерно на **0,82 процентного пункта**.
Основные положительные вклады дали Clarins, Payot и Valmont; предложены аудит промо Clinique и проверка причин снижения доли Sisley и Shiseido.
Факторное разложение неполное: оно пропускает бренды, представленные только в одной неделе.

## Задание 4. SQL: продажи и остатки

**Что сделал:** подготовил запрос ClickHouse с динамическими границами месяцев для расчёта продаж, средневзвешенной цены, среднемесячного объёма за три месяца и разницы с остатком.

**Результат:** подготовлен запрос по товарам с продажами в последнем полном месяце, использующий остатки на общую максимальную дату таблицы; запрос топ-5 брендов отсутствует, результатов выполнения SQL нет.

## Задание 5. SQL: скользящий WAU

**Что сделал:** предложил два SQL-варианта подсчёта уникальных пользователей — соединение событий по семидневному диапазону и объединение дневных состояний `uniqExactState` оконной функцией.

**Результат:** подготовлены два запроса без результатов выполнения; дни без событий не добавляются, поэтому оконный вариант с `ROWS` соответствует семи календарным дням только при непрерывном ряде дат.
